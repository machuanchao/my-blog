# 周末在奥克兰徒步，意外发现一个安静小湖
> 不用赶行程，漫无目的的闲逛，反而最容易遇到惊喜。
## 出行简单记录
| 项目 | 信息 |
| ---- | ---- |
| 天气 | 多云，微风 |
| 出发时间 | 上午9点 |
| 路程 | 短途，没有高强度爬坡 |
## 过程
本来只是想出门兜兜风，没有定目的地，沿着小路随便开。
开到半路看到路边一个不起眼的入口，停车走进去，走大概十几分钟，就看见了这个湖。
人很少，只有两三个本地人在遛狗。水面很平静，风吹过来的时候，树叶沙沙响。
坐在湖边石头上歇了半小时，什么都不用想，单纯发呆。
路上看到几棵老树，还有几只野鸭在水面游。没有游客扎堆，没有小卖部，原生态。
## 一点感想
平时总习惯把时间安排得满满当当，做事追求目标和结果。
偶尔这种毫无计划的出门，反而能让人松下来。
不用打卡，不用拍照发很多社交平台，只是单纯感受环境。
## 小提示
- 小路部分有点泥泞，建议穿防滑鞋子
- 没有厕所和补给，随身带水
- 尽量不要留下垃圾，带走所有随身废弃物
