# 松下 SD2501 成功吐司配方（10oz面粉｜菜单01）
本次为 **本人实测完全成功** 配方，口感松软、不酸、不硬、不塌陷，适配手提秤盎司（oz）单位，适合日常长期使用。

## 基础说明
- 适用机器：松下 SD2501
- 使用菜单：**01 Basic 基础吐司**
- 面粉基准：**1平碗面粉 = 10oz（约283g）**
- 机器设置：尺寸 L / 烤色 Medium（中等）
- 程序时长：约 4小时05分
- 适用场景：现做现烤（**禁止长时间预约过夜**，防发酸、发硬）

## 精准配方（oz 单位｜直接秤）
### 奶香鸡蛋版（主推、口感最好，含奶粉可选）
- 高筋面粉：**10.0 oz**
- 鸡蛋：**2.8 oz（约2个）**
- 清水：**2.2 oz**（加奶粉就从原来2.4oz减0.2oz水）
- 白糖：**1.0 oz**
- 食盐：**0.25 oz**
- 奶粉：**0.3 oz（可选，乳粉，不要甜奶粉）**
- 猪油：**1.0 oz**
- 干酵母：**0.25 oz**

> ✅ 不加奶粉：水依旧用 2.4 oz
> ✅ 奶粉放面粉里面拌匀，不要和酵母堆一起

### 无鸡蛋备用版（纯纯水软吐司，奶粉可选）
- 高筋面粉：**10.0 oz**
- 清水：**6.0 oz**（加奶粉从6.2oz减0.2oz水）
- 白糖：**1.0 oz**
- 食盐：**0.25 oz**
- 奶粉：**0.3 oz（可选）**
- 猪油：**1.0 oz**
- 干酵母：**0.25 oz**

## 标准投料顺序（核心！不酸不塌关键）
1. 面包桶底部：先放 **鸡蛋 + 清水 + 猪油**（全部液体）
2. 倒入全部面粉，奶粉、糖、盐和面粉混合拌匀
3. 面粉完全盖住底层液体（隔绝水盐）
4. 干酵母 **单独撒在面粉最顶层**
> 铁律：**酵母绝对不能直接接触盐水、蛋液**，避免提前发酵发酸

## 完整操作步骤
1. 安装好面包机搅拌叶片，按顺序放入所有食材
2. 盖盖，选择菜单 `01 Basic`
3. 尺寸选 `L`，烤色选 `Medium`，启动程序
4. 全程无需开盖，避免温度流失、发酵失败
5. 程序结束蜂鸣、显示 `End` **立刻取出面包**
6. 倒扣放凉，不要留在机器内保温（杜绝发硬）

## 避坑总结（本人翻车经验）
1. ❌ **不要预约10小时过夜**：长时间静置发酵过度，必酸、酒味重、组织差
2. ❌ 烤色不要选 Dark：外皮过干、整体偏硬
3. ✅ 出炉马上取出：机器自带1小时保温，闷放会快速风干变硬
4. ✅ 新西兰低温环境属于正常发酵偏慢，无需改动配方
5. ✅ 此配方为机器最佳容量，**不可以加两碗面粉（20oz）**，超量揉面不均、伤电机
6. ✅ 奶粉选无糖全脂奶粉最佳；甜奶粉会额外加糖，容易上色过重

## 成品效果
- 组织细腻、松软拉丝
- 奶香浓郁（加奶粉之后更明显），无酸味、无过重酵母味
- 外皮适中，冷却后不发干、不发硬
- 适合日常早餐、切片食用
